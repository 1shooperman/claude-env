# Commands

All claudenv commands are subcommands of the `claudenv` shell function.

| Command | Description |
|---------|-------------|
| [`claudenv`](pick) | Interactive env picker |
| [`claudenv <name>`](activate) | Activate a named env |
| [`claudenv deactivate`](deactivate) | Deactivate the current env |
| [`claudenv config`](config) | Create a new env |
| [`claudenv list`](list) | List all envs |
| [`claudenv remove`](remove) | Delete an env |
| [`claudenv upgrade`](upgrade) | Upgrade claudenv to a release |
| [`claudenv uninstall`](../installation#uninstalling) | Remove claudenv |
| [`claudenv help`](help) | Show command reference |
