# Support

## Getting help

- **Docs:** [README](README.md) and the [documentation site](https://1shooperman.github.io/claude-env/) cover installation, commands, prompt integration, and known limitations.
- **Questions / usage help:** [open an issue](https://github.com/1shooperman/claude-env/issues/new) with the `question` label.
- **Bugs:** [open an issue](https://github.com/1shooperman/claude-env/issues/new). Include:
  - OS and version
  - Shell and version (`bash --version` / `zsh --version`)
  - Prompt framework / theme (e.g. oh-my-zsh, starship), if any
  - Steps to reproduce, expected vs. actual behavior
- **Feature requests:** [open an issue](https://github.com/1shooperman/claude-env/issues/new) describing the use case.
- **Security vulnerabilities:** do **not** use public issues. See [SECURITY.md](SECURITY.md).

Search [existing issues](https://github.com/1shooperman/claude-env/issues?q=is%3Aissue) first; your question may already be answered.

## Contributing

Only the latest commit on `main` is supported. See [SECURITY.md](SECURITY.md).
